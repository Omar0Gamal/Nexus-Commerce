# ADR 0001: Record Architecture Decisions

Date: 2026-09-30
Status: Accepted

## Context

Architectural trade-offs across routing, storage, and background processing require version-controlled documentation alongside the source code.

## Decision

Record significant technical decisions in `docs/adr/` using the Michael Nygard ADR format (`Context`, `Decision`, `Consequences`).

## Consequences

- Architectural changes and infrastructure constraints are tracked in Git history.
- Significant boundary or protocol changes require a corresponding ADR entry.
